LINKUP — Especificaciones iniciales de la web (MVP)

Objetivo de la primera versión:
Crear una web sencilla, moderna y principalmente adaptada a celular, donde jóvenes puedan descubrir oportunidades y eventos de forma rápida. La prioridad no es desarrollar todas las funciones de la visión final, sino tener una primera versión funcional que permita validar el concepto.

1. Inicio
La página principal debe explicar rápidamente qué es LinkUP:
> LinkUP — Conectando el talento joven con su primera gran oportunidad.

Debe tener:
Buscador principal.
Acceso a Oportunidades y Eventos.
Categorías principales.
Algunas oportunidades destacadas.
Próximos eventos.
Botón para explorar todas las oportunidades.
Llamado a crear perfil, aunque el registro no debería ser obligatorio para navegar. (Opcional)

La sensación visual debe ser moderna, limpia, juvenil y tecnológica, pero sin verse demasiado corporativa.

2. Oportunidades
Será el apartado principal de la web.
Debe mostrar un catálogo de:
Becas
Voluntariados
Pasantías
Cursos
Programas
Intercambios
Concursos
Otras oportunidades para jóvenes

Debe contar con:
Buscador + filtros básicos, por ejemplo:
Categoría
Modalidad: presencial / virtual / híbrida
Ubicación
Área
Edad
Fecha límite

Las oportunidades aparecerán mediante tarjetas con información resumida:

> Nombre
Organización
Categoría
Ubicación / modalidad
Fecha límite
Botón “Ver oportunidad”
Botón para guardar

3. Página individual de oportunidad
Al seleccionar una oportunidad, debe abrirse una página con:
Nombre
Organización
Descripción
Requisitos
A quién está dirigida
Beneficios
Modalidad
Ubicación
Fecha límite
Información adicional
Enlace oficial
Botón principal:
“Postularme”

Este botón llevará a la página oficial de la organización. LinkUP inicialmente no gestionará la postulación directamente.

4. Eventos
Sección independiente de oportunidades.
Su objetivo es publicar información sobre:
Charlas
Foros
Ferias
Talleres
Conferencias
Webinars
Networking
Congresos
Otros eventos abiertos al público.

Debe ser principalmente informativa, no necesitamos desarrollar un sistema de reservas.

Los eventos pueden tener:
Nombre
Fecha y hora
Lugar
Modalidad
Organización
Descripción
Imagen
Precio/gratuidad
Link de registro o información

Puede tener filtros sencillos por tipo, ubicación, modalidad y fecha.

5. Enviar una oportunidad/evento
Queremos que los usuarios puedan avisarnos de nuevas oportunidades o eventos.
Una sección:
> ¿Conoces una oportunidad?
o
> ¿Conoces un evento?
Inicialmente puede ser mediante un formulario sencillo que llegue al administrador. También queremos dejar abierta la posibilidad de recibir información mediante WhatsApp.

Importante: ningún contenido enviado por usuarios se publica automáticamente. Todo debe ser revisado por el equipo antes de publicarse.

6. Panel administrativo
Esta es una función importante del MVP.
Necesitamos poder administrar la plataforma sin depender del programador para cada publicación.
Desde el panel deberíamos poder:
Crear oportunidades.
Editar oportunidades.
Eliminar/desactivar oportunidades.
Crear eventos.
Editar eventos.
Eliminar/desactivar eventos.
Marcar contenido como destacado.
Revisar contenido enviado por usuarios.
Gestionar fechas de vencimiento.
Idealmente, las oportunidades vencidas deberían poder identificarse fácilmente.

7. Perfil de usuario — básico / opcional para primera versión
Para el MVP podemos mantenerlo sencillo.
El usuario podría registrarse y completar:
Nombre
Edad
Ubicación
Estudios
Intereses
Habilidades
Idiomas
Y posteriormente utilizar esta información para recomendaciones.
No es necesario desarrollar todavía un sistema avanzado de IA o matching.

8. Guardados — si es sencillo de implementar
Permitir que un usuario pueda guardar:
⭐ Oportunidades
⭐ Eventos
para revisarlos posteriormente.
Esto puede quedar como una función secundaria si aumenta demasiado la complejidad del MVP.


9. Diseño y experiencia
Prioridad:
Mobile-first.
La mayoría de usuarios probablemente llegará desde redes sociales o WhatsApp, por lo que debe funcionar especialmente bien en celular.

La navegación debe ser muy sencilla. Idealmente:
Inicio | Oportunidades | Eventos | Para ti | Perfil
No queremos demasiados menús ni información innecesaria

La idea es que un usuario pueda hacer:
Entrar → explorar → encontrar algo interesante → ver información → acceder al sitio oficial.

La idea es que esta primera versión sea sencilla pero suficientemente funcional para ponerla frente a usuarios reales y comprobar si LinkUP realmente les ayuda a descubrir oportunidades.
